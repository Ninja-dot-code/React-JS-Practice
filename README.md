## About

This repository contains hands-on React practice code.  
The goal is to strengthen core concepts, write clean and reusable components, and build real problem-solving skills.

Focus areas:
- Functional components & Hooks
- Props, State, and Data flow
- Custom Hooks
- Component composition & patterns
- Responsive UI with clean CSS / Tailwind
- Practical mini-projects

No fluff. Just code that works and is easy to read.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Ninja-dot-code/React-JS-Practice.git

# Navigate into the project
cd React-JS-Practice

# Install dependencies
npm install

# Start the development server
npm run dev
